────────────────────────────────────────────────────────────────────────────────
 1. RECONCILIATION TAB
────────────────────────────────────────────────────────────────────────────────

 1.1  Date Range Filter on Reconciliation Tab
      - Add date_from / date_to filters to GET /files/{id}/reconcile/results
      - Filter on ReconciliationResult.booking_date
      - Add two date inputs to the reconciliation toolbar (same style as
        the sheet filter bar already has)

 1.2  Variance Range Filter
      - Already supported in the API (variance_min, variance_max)
      - Currently not exposed in the UI
      - Add two number inputs: "Variance Min" and "Variance Max"

 1.3  Customer Name Search
      - ReconciliationResult already has a customer_name column
      - Add a text input that filters via customer_name.ilike()

 1.4  Sortable Columns on Reconciliation Table
      - Add sort_by and sort_order query params to the API
        (e.g. sort_by=variance&sort_order=desc)
      - Clickable column headers in the UI that toggle asc/desc

 1.5  Inline Revised Remark Editing
      - ReconciliationResult already has revised_remark and final_remark columns
      - Add a PATCH /files/{id}/reconcile/results/{result_id} endpoint
      - Make the Revised Remark cell editable in the table (click to edit,
        press Enter to save, auto-calls the PATCH endpoint)

 1.6  Bulk Remark Override
      - Checkbox column in the reconciliation table
      - "Mark as Revised" toolbar button
      - POST /files/{id}/reconcile/results/bulk-update accepts list of IDs
        + revised_remark value

 1.7  Markup/Booking Charges Detection Toggle
      - The current threshold is hardcoded: ±10 around 300
      - Expose as a configurable field on the UploadedFile or a settings table
      - Admin can adjust the markup value and tolerance per file/organisation

 1.8  Export Filtered Results to Excel
      - The existing download endpoint exports everything
      - Add query params (same filters as the results endpoint) to
        GET /files/{id}/reconcile/download so the Excel only contains
        the currently filtered rows

 1.9  Summary Panel Drill-Down
      - The summary chips (Matched 25, Variance 24, etc.) already exist
      - Clicking a chip should set the appropriate filter and reload the table
      - Currently filterByRemark() is a stub — wire it to the new
        comparison/source-existence selects

 2. UPLOAD & INGESTION
────────────────────────────────────────────────────────────────────────────────

 2.1  Re-upload / Replace File
      - Allow re-uploading a new version of an existing file
      - Wipe old staging_records + reconciliation_results for that file_id
      - Re-run ingestion and reconciliation automatically

 2.2  Upload Validation Report
      - After ingestion, show a per-sheet report:
          · Rows ingested
          · Rows skipped (blank / header-only)
          · Columns detected
          · PNRs found / missing
      - Already available from StagingRecordService return values, just
        needs a dedicated response field and UI card

 2.3  Duplicate PNR Detection at Upload
      - After ingestion, query for PNRs that appear in more than one row
        within the same sheet
      - Show a warning banner on the sheet data page

 2.4  Column Auto-Mapping UI
      - If a new sheet format is uploaded and _SHEET_FIELD_MAP has no entry,
        show a mapping screen: "Which column is the PNR?", "Which is the date?"
      - Save the mapping per sheet_name to a new sheet_column_mappings table
      - StagingRecordService reads from that table first before _SHEET_FIELD_MAP

 3.2  Freeze / Pin Columns

 3.3  Cell-Level Search (highlight)

 3.4  Row-Level Mark as Processed

 3.5  Raw Data JSON Viewer
      - Clicking a row expands a side panel showing the full raw_data JSON
      - Useful for debugging unexpected reconciliation outcomes

 6. API & BACKEND IMPROVEMENTS
────────────────────────────────────────────────────────────────────────────────

 6.1  Reconciliation Result Versioning
      - Each time reconcile is re-run, archive the old results with a
        run_number instead of deleting them
      - New table: reconciliation_runs (id, uploaded_file_id, run_at, row_count)
      - reconciliation_results gets a run_id FK

 6.2  Async Reconciliation with Progress Bar
      - Reconciliation can be slow on large files
      - Mirror the existing upload-async + SSE progress pattern:
        POST /files/{id}/reconcile-async → job_id
        GET  /files/{id}/reconcile/progress/{job_id} → SSE stream
      - Show a progress bar on the frontend while reconciliation runs

 6.3  Webhook / Notification on Completion
      - POST a JSON payload to a configurable URL when reconciliation finishes
      - Store webhook_url on the Organisation model

 6.4  API Key Authentication
      - Simple API key table: api_keys (id, org_id, key_hash, created_at)
      - FastAPI dependency that checks X-API-Key header
      - Lets external systems trigger reconciliation programmatically

 6.5  Pagination Cursor Mode
      - Current pagination uses OFFSET which is slow on large tables
      - Add a cursor-based alternative: ?after_id=<last_seen_id>
      - Keeps page loads fast even with 100k+ reconciliation rows


────────────────────────────────────────────────────────────────────────────────
 7. UX / FRONTEND
────────────────────────────────────────────────────────────────────────────────

 7.1  Keyboard Shortcut: Tab through sheets
      - Left/Right arrow keys switch between sheet tabs when focus is on
        the tab bar

 7.2  Sticky Filter Bar on Scroll
      - The reconciliation toolbar should stay visible when scrolling
        the results table (position: sticky)

 7.3  Page Size Selector for Reconciliation Table
      - Currently hardcoded pageSize = 50
      - Add a rows-per-page dropdown (25 / 50 / 100 / 200) matching the
        sheet data table

 7.4  Deep-Link to Tab
      - Append ?tab=reconciliation to the URL when switching to that tab
      - On page load, read the query param and auto-activate the right tab
      - Makes sharing a direct link to the reconciliation view possible

 7.5  Toast Notifications
      - Replace alert() calls (Run button error) with a non-blocking
        toast/snackbar component

 7.6  Dark Mode
      - The design uses CSS custom properties already (--md-sys-color-*)
      - A prefers-color-scheme media query + a toggle button would flip
        all colours with minimal CSS changes


────────────────────────────────────────────────────────────────────────────────
 8. DATA QUALITY
────────────────────────────────────────────────────────────────────────────────

 8.1  PNR Normalisation
      - Different sheets sometimes have the same PNR with different casing
        or whitespace (e.g. "ABCD12" vs "abcd12" vs " ABCD12 ")
      - Normalise to uppercase + strip on ingest in StagingRecordService
      - Already done for the indexed pnr column, but raw_data keeps the
        original value — reconciliation uses raw_data keys, so normalise
        there too before aggregation in ReconciliationService

 8.2  Amount Sanity Check
      - Flag rows where cost_net is negative (refund > sale)
      - Add a new remark label: "Negative Cost" or "Refund Exceeds Sale"

 8.3  Missing Mandatory Column Warning
      - If a required column (RecordLocator, Formatted PNR, GDS PNR) is
        absent from a sheet, surface a banner on the sheet data page rather
        than silently producing zero aggregates
